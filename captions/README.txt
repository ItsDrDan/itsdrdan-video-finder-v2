CAPTION FILES GO HERE

Name each WebVTT file with the YouTube video ID.

Example YouTube URL:
https://www.youtube.com/watch?v=59yqaBoKWss

Caption filename:
59yqaBoKWss.vtt

After adding or replacing caption files, run the GitHub Action:
"Update YouTube video library"

That will update videos.json so the website knows which videos have searchable transcripts.
